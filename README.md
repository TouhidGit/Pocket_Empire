# Pocket Mogul

An idle business tycoon game for Android, by TouhidGit.

You start broke, with big dreams. Tap the coin to earn your first dollars, and tap fast to build a streak worth up to double cash per tap. Then:
- open 12 businesses, from a lemonade stand to a space colony, that earn money every second
- trade stocks that react to breaking news
- buy and sell property as the housing market rises and falls
- collect 24 cars, homes, aircraft, yachts and treasures for reputation
- pass your empire to your heir to earn permanent **Legacy Stars**

It also has daily login bonuses, random events, bonus briefcases and goals to guide you.

## Project layout
| Path | What it is |
|---|---|
| `game/` | The game itself (HTML, CSS and JavaScript). Open `index.html` to play in a browser. |
| `game/img/` | Photos, 3D icons, avatars and stock logos. See [CREDITS.md](CREDITS.md) for who made them and their licenses. |
| `app/` | A small Android app that shows the game full-screen. |
| `.github/workflows/build-apk.yml` | GitHub Actions builds the APK on every push and publishes it under **Releases**. |

To get the APK, see [HOW_TO_GET_APK.md](HOW_TO_GET_APK.md).
